## Use and boundaries

Write **`Analizza: tema`** (also `Miriam, analizza …` or `prepara un brief …`) in the Conversation. The persistent work appears there on web, SwiftUI and Compose; expand it to inspect its contract, assumptions, meaningful events, unadopted Contribution, citations and history. Select the work when controlling it; commands carry its exact current revision. An ambiguous/unsupported instruction is not applied.

Any currently eligible contributor may use **Pausa / Ferma / Riprendi** and these scoped conversational instructions:

| Instruction                                | Bounded behavior                                                                                                                                                                                                                  |
| ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `stato`                                    | Inspect current operational state.                                                                                                                                                                                                |
| `formato: elenco`, `sintesi` or `dettagli` | Version presentation guidance; preserve objective, assumptions, restrictions and prior pause/stop.                                                                                                                                |
| `ipotesi: …`                               | Append an attributed analytical assumption in a new contract version; never accept information or modify a governed object. Existing anchors remain.                                                                              |
| `reindirizza: obiettivo`                   | Propose a replacement direction. Preserve the current contract when another participant's existing direction is involved. Clarify the actual conflicting instructions, not a vote of all members or a requester-owned permission. |
| `obiezione: …` / `limita: …`               | Record an attributed blocking restriction; move to Needs Input.                                                                                                                                                                   |
| `confermo: issue-id` / `ritiro: issue-id`  | Clarify a specific current proposal / withdraw one's own instruction. UI offers the applicable buttons. No representation or reusable authority is created.                                                                       |
| `input: …`                                 | Supply attributed material for a missing-input request, without resolving other objections or replacing anchors.                                                                                                                  |
| `usa contesto aggiornato`                  | Explicitly permit refreshed relevant references for analysis; existing anchors/objections and editorial/governed boundaries remain.                                                                                               |

After resolving a blocking issue, resume explicitly. Pause/stop never undo history or obligations. Completed records historical output production; a later relevant change marks the result **Potentially Outdated**, without restarting it. Contributions remain unadopted; this slice adds no adoption/export/execute shortcut. Existing Artifact/Task/Calendar/Email governance remains authoritative.

## Conservative initiative and limits

Autonomous initiation currently considers explicit open analysis/comparison questions with at least two pertinent shared sources beyond the question itself and an available analysis provider. It records Miriam provenance without impersonating a user; the product-owned shared analysis capability requires an eligible contributing membership to remain exercisable. There is no borrowed requester credential or private-resource access. At most four queued/running works per Workspace is an operational attention/concurrency setting, not domain governance.

Normalized topic matching prefers an existing work, including paused/stopped/completed work; it cannot bypass control or automatically restart a completed result. This is deliberately narrow lexical matching, not semantic deduplication. Free-form control interpretation, arbitrary scope/anchor replacement and automatic resolution of material multi-member disagreement are outside this increment. A departed participant's unresolved instruction is retained; no succession or silent override is manufactured. Reusable mandates are not added here.

The ordinary Specialist uses the existing configured provider seam. With no valid AI configuration, work becomes Needs Input with an explicit configuration error; production does not synthesize a fake brief. Real-model quality, cost and service-boundary verification remain WIRE/pending. Test doubles are imported only by explicit test processes.
