# RIMIAM Web workflows

**Release scope, 18 November 2026.** The Railway Web beta includes slash commands, the document collector and inline AI-limit notices. Invitations from personal contacts at Workspace creation are available in the local build. See the [deployment record](RAILWAY_DEPLOYMENT.md#current-setup) for live verification.

Use this map to follow a person’s action through the product and find the implementation or acceptance evidence. The in-app **Guida dello spazio** explains these flows in Italian. Type `/guida` in an empty composer or open **Strumenti → Guida e comandi**. The guide and the picker both read the [Web command catalogue](../../src/client/composer-actions.ts). Selecting a command opens a tool or prepares text. Any write, disclosure or external action still goes through its own confirmation and server checks.

## Personal utilities on Home

**Oggi** lists relevant personal and Workspace reminders and appointments by time. Choose **Solo io** or a named space before creating an item. An invitation awaiting your RSVP is marked **Da confermare**. You can collapse the agenda on Home. In the Web sidebar, **Oggi** opens the daily agenda on its own at `/#oggi`, including after returning from a workspace or a private conversation. The sidebar stays available in the personal archive and in **Tu ed Emme**. On narrow screens the panel icon opens it. Group spaces sit directly below **I tuoi spazi**.

**Tu ed Emme** resumes your last private conversation. You can start another, reopen an earlier one or consult a named Workspace until you choose **Termina**. The result stays private until you choose a destination and share it. Private research can be requested independently, with a separate notification opt-in for each request. **I miei documenti** opens the private archive, where you can download an editable document and share a copy with a named space. [Private tools](PERSONAL_CHAT.md) · [Agenda acceptance](../../tests/e2e/home-agenda.spec.ts)

## Return to a conversation · local Web redesign

On a phone, **Attività** beside the Chat and Condivisi tabs opens the space Goal, items needing attention, Emme’s reading status and active work. A small dot indicates ongoing work or something to check. A circled minus means the AI service is unconfigured; open the panel for details. Group messaging stays available. Closing the panel returns to the same point in the conversation. [Responsive header scenario](../../tests/e2e/workspace-header.spec.ts)

Home interleaves groups and direct chats by their most recent message or file. A new member opens at the latest exchange and can scroll back through earlier history. Opening a group takes you to its newest unread mention, or to the bottom when there are none. The **@** opens the oldest unseen mention. **Vai in fondo** scrolls past earlier messages without clearing their mentions. The original message’s menu puts **Rispondi** and **Chiedi a Emme** in the main composer with the selected quote. **Richiedi una risposta** creates a personal alert for each named recipient. Their quoted reply or **Già risposto** clears only that alert. [Reading and mentions](../../tests/e2e/conversation-reading.spec.ts) · [Quoted reply](../../tests/e2e/message-question.spec.ts)

**Scrivi a un contatto** opens the private conversation between two existing contacts. The first message puts it in the recipient’s Home. Files stay between the two people. Typing an assistant address or slash command explains the recipient and offers a shortcut to the personal recap. Sending still delivers an ordinary message to the contact. Each can enable or withdraw consent to a personal AI recap of the complete exchange. The result belongs only to the requester. **Crea uno spazio con…** preselects the contact for an ordinary invitation and accepts an optional introduction and newly chosen files. The private exchange stays separate. [Two-person journey](../../tests/e2e/direct-chat.spec.ts) · [Consent and privacy regressions](../../tests/direct-chat.test.ts)

## First session with two people

1. Sign in with two distinct verified accounts in separate browser profiles. On a clean local installation use the [README first-run steps](../../README.md#try-two-accounts).
2. In the local Web build, **Crea un nuovo spazio** at the top of Home opens a dedicated form. Enter a name, then type the invitee’s email or select a personal contact. Confirm the shared-history notice and choose **Crea spazio e invita**. The invitation is recorded with the space. The recipient can find it under **Inviti ricevuti** or open the personal email link, sign in or register with the invited address, and choose **Accetta invito ed entra** to enter the original chat. Sending email requires the installation’s transactional mail provider. For an existing space, **Invita** in the chat header also offers a personal link to copy. Copying a workspace URL alone does not invite a new member. [Two-account and new-registration checks](../../tests/e2e/workspace-create-invites.spec.ts)
3. Send a message to the group. To ask for an AI reply, use **Chiedi a Emme** on the draft or on a specific message. Check the original message if a reply fails. A rolling usage limit can prevent processing while the chat and worker are online. After capacity returns, retry that reading from the original request.
4. Try **/documenti**, **/task** and **/contesto**. A file or observation is shared material. A saved task tracks work. A proposed interpretation becomes an accepted reference only through a separate editorial act. The second account can inspect the result according to its access.

## Reading and sharing on the redesigned Web

Open **Chat** to resume reading. **Condivisi → Media** shows thumbnails by date. Close an image to return to the same filters or choose **Vai al messaggio** to read its original exchange. On touch devices, **Scatta una foto** adds a preview to the draft. The operating system handles the capture. **Invia** shares the result. The paperclip and drag-and-drop prepare one attributed message with its caption and ordered files. A star belongs to the person who adds it.

In a file preview, the star saves that file to your own **Preferiti**. The preview shows pending extraction or a required media consent before Emme can read the file. **Chiedi a Emme su questo file** opens a draft in the group chat with that exact document version attached as a reference. Send the question when ready. The file citation under Emme’s reply reopens the version she used. A saved page uses a short domain and path in the list and opens its full original address.

**Nuovo documento** shows the destination before saving. The receipt opens the exact saved version under **Documenti di lavoro** in the selected collection. If a newer version exists, the receipt opens the saved one in **Storia del documento**. A document requested from Emme starts in **Documenti personali** and can be shared explicitly from its preview.

On phone Web, tap the writing field to reveal the paperclip and message actions, use Return for a new line and tap **Invia** to send. On desktop, Enter sends and Shift+Enter adds a line. Beside **Chat** and **Condivisi**, the member count opens **Persone e accesso**. An eligible inviter can also open **Invita** from the header. Tap a human author’s name or photo in a conversation to open their contact card. **Account personale → Il mio profilo** contains the profile photo and optional phone number. Open **Aspetto** to change the theme or its accent. **Metodi di accesso** shows Google and Microsoft sign-in availability and linking. **Collega calendario** is visible next to **Oggi**, including when the agenda is closed. It becomes **Calendari collegati** when a personal calendar is linked. The account menu uses the same labels for the calendar connections in the current space. Calendar consent is separate from identity sign-in. When one message has several suggestions from Emme, expand its single summary to inspect the individual suggestions.

**Condivisi** names the space in its header. From the chat tab, **Chiudi** returns to chat. When one panel opens another, the back arrow leads to the parent, for example from an invitation opened through **Persone e accesso** back to the participant list. The list reserves a photo or initials for each person. Select an active member’s name to view their profile. **Dettagli invito** shows delivery information, and **La mia partecipazione** groups the actions for leaving or relinquishing access management.

Choosing a tool keeps **Strumenti** expanded. On wide Web layouts the conversation and tool sit side by side. On a narrow phone, closing the tool returns focus to its entry in the open menu. [Web navigation regression](../../tests/e2e/product-shell.spec.ts).

**Strumenti → Contesto** opens a private consultation. The result stays with the reader until they choose **Condividi in chat**. Asking for a document saves an editable Markdown file in **Documenti personali**. A named sharing action creates a separate copy in the selected Workspace. Downloading and reuploading edited bytes preserves the original.

## Tools on the local Web build

- **Attività e argomenti** initially shows compact summaries. Open an item for its description, author and sources. Archive an argument from its controls. Include archived items to restore it.
- **In programma** shows the nearest deadlines first. In the task list, pending offers addressed to you lead the current page. Open an offer to see who sent it and whom it addresses. **Accetta incarico** moves it into **Solo mie**. **Rifiuta incarico** records your answer. **Spunti dal contesto** opens separately. Choosing a suggestion starts an editable draft. A task is created only when a contributor saves it. Comments, Standby and completion remain available according to responsibility.
- **Condivisi / Documenti personali** keeps files, photos, notes and links in one chronological collection. Add links next to file uploads, then filter by date, type or search term. Ordinary URL mentions point back to the original message. On each row, **Rimuovi → Nascondi su questo dispositivo** hides the item in this browser or native installation for this account and space. On iOS and Android, the preference also belongs to the configured server and persists in device-protected storage. **Mostra elementi nascosti → Mostra di nuovo** brings it back. The contributing uploader can also choose **Rimuovi per tutti** on a file version and restore it from **File ritirati**. An explicitly shared link remains in its original message.
- **Fonti e ricerca** shows a small photo and a readable processing status. The uploader can withdraw a file version after confirming. Its original and preview become unavailable in the space. The chat retains a marker and the author can restore the version under **File ritirati**. Copies already downloaded or shared independently remain outside this operation.
- On opening or resuming the Web app, a tab verifies its build against the uncached release endpoint. It also checks when connectivity returns and every 30 seconds while visible. An idle outdated tab reloads at the same URL. A tab with unfinished edits blocks interaction and offers «Aggiorna ora». Offline or unverifiable sessions stay locked and retry; an old build’s tagged API requests receive HTTP 409 before a command runs. Tabs running the previous optional updater can require one manual reload when this policy first ships. The public data and beta notices remain readable without JavaScript.

For private email, open **Strumenti → Email → Le tue caselle**, choose Gmail or Outlook and complete the provider consent. Review the saved draft and recipients before authorizing a send. [Email workflow and receipt states](EMAIL.md).

## When an action seems to have done nothing

- **The invitee sees no space.** Use the verified account addressed by the invitation, then check incoming invitations on Home or open the personal invitation link. Being listed in someone's contacts does not admit them.
- **A message is visible, but Emme has not replied.** Check whether it was a group message or an explicit request. When capacity returns, open the original request’s **Opzioni del messaggio** and choose **Riprova questa richiesta a Emme**. In Context, **Letture da verificare** groups reading failures by cause. A failed reading produces no proposal to accept.
- **An external send has an uncertain outcome.** Inspect the original email or calendar operation and use its reconciliation flow. Sending a second copy can duplicate an effect the provider already performed.
